# Nibbles Filter

Become your Nibble. A face-tracked filter that turns any of the 8,888 Nibbles into a live puppet for recorded clips and livestreams.

**Live:** https://geaux-eth.github.io/nibbles-filter/

- On-device face tracking (MediaPipe): head tilt/turn, blinks, talking mouth
- Auto background removal, six backgrounds plus custom upload
- Record 9:16, 1:1 or 16:9 clips with mic audio
- Stream mode for OBS (use Green screen + Chroma Key)
- Wallet gating via `ownerOf` on Ethereum mainnet (contract `0x5e52d41f0e40d7cdb204db0d09659846f7404547`)
- Rig editor for tuning eyes, mouth, neck pivot and animated effects per token
